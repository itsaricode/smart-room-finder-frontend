# 🏠 Smart Room Finder — Frontend

The frontend application for **Smart Room Finder**, a multi-platform project developed as a Final Year Project (FYP).

This application provides the user-facing web interface and communicates with the Smart Room Finder backend through REST APIs.

## 🚀 Tech Stack

* HTML
* CSS
* JavaScript
* React Type Script

## ✨ Features

* Interaction with backend REST APIs
* Website pg and Admin dashboard
* Responsive user interface

## ⚙️ Installation & Setup

### 1. Clone the repository


git clone https://github.com/itsaricode/smart-room-finder-frontend.git


### 2. Open the project


cd smart-room-finder-frontend


### 3. Install dependencies


npm install


### 4. Start the development server


npm run dev
